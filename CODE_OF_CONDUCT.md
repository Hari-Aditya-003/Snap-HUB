# Code of conduct

Treat contributors with respect, welcome questions from people new to the project, and keep feedback focused on the work. Give people credit for their contributions and respect their privacy. Harassment, threats, discriminatory remarks, and sharing someone else's private information without permission are unacceptable.

These standards apply to project spaces, including issues, pull requests, reviews, and discussions. Maintainers may remove content, lock a conversation, or restrict participation when needed.

Report abusive content using the GitHub **Report content** menu or GitHub Support's [abuse report form](https://support.github.com/contact/report-abuse). Keep sensitive details in the report.
