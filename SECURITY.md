# Security policy

Use GitHub's [private vulnerability report form](https://github.com/Hari-Aditya-003/Snap-HUB/security/advisories/new) to reach the maintainers. Include the affected commit or version, the affected component, the impact, and enough detail to verify the report with disposable data in a local or self-hosted instance.

Keep credentials, access links, private event media, and personal data out of reports. Use public [GitHub Issues](https://github.com/Hari-Aditya-003/Snap-HUB/issues/new/choose) for ordinary bugs and [GitHub Discussions](https://github.com/Hari-Aditya-003/Snap-HUB/discussions) for help with installation.
